# 电子书阅读器 v1.3.0

一款专为词典笔设计的小说阅读器插件，支持本地 `.txt` 小说阅读，并提供网页上传方式。

基于 [PenMods](https://github.com/PenUniverse/PenMods) 插件环境开发。

> **v1.3.0 重要更新**：修复了上传功能的致命缺陷。此前上传**只在源文件字节数恰为 3 的倍数时才能成功**，
> 且失败时还会给出误导性提示。详见 [更新日志](#更新日志-v130) 与 [CODE_REVIEW.md](CODE_REVIEW.md)。

## 功能特性

### 核心阅读

- 自动扫描 `/userdisk/Music/小说/` 目录下的 `.txt` 小说文件
- "我的书架"独立页面，显示所有已扫描和已阅读的小说
- 支持手动输入书名打开小说（无需输入完整路径）
- 自动记录每本小说的阅读进度，下次打开自动恢复
- **逐章加载**：每次只加载当前章节，进入阅读器极速打开
- **章节导航**：滚动模式下章节顶部"上一章"、底部"下一章"按钮，分页模式章尾"下一章"按钮
- 支持书签功能，可添加、查看、删除书签
- 支持章节识别与跳转（自动识别"第X章"等中文章节格式）
- **书架进度**：显示整本书总阅读进度
- **菜单进度**：显示当前章节阅读进度

### 阅读设置

- 三种字号可选：小（13px）、中（15px）、大（18px），**默认中号**
- 三种行距模式：紧凑、标准、宽松
- 七种阅读主题：默认、白色、黄色、绿色、黑色、粉色、蓝色
- 支持自动翻页，可自定义间隔秒数（1~999 秒）

### 两种阅读模式

**分页模式（默认）**
- 适合专注阅读，一页一页翻
- 点击/滑动翻页
- 章末自动显示"下一章 →"按钮

**滚动模式**
- 适合快速浏览，上下滑动滚动查看全文
- 章节顶部显示"← 上一章"按钮，底部"下一章 →"按钮
- 右下角 ☰ 按钮打开菜单
- 可随时在菜单中切换滚动/分页模式

### 交互操作

| 操作 | 效果 |
|------|------|
| 点击屏幕左 1/3 | 上一页（分页）/ 上翻一屏（滚动） |
| 点击屏幕右 1/3 | 下一页（分页）/ 下翻一屏（滚动） |
| 点击屏幕中间 1/3 | 打开菜单 |
| 长按屏幕 | 返回首页 |

### 网页上传

- 首页一键启动上传服务，手机/电脑浏览器打开 IP 即可上传 `.txt` 小说
- 无需安装任何工具，纯网页操作，支持拖拽选择文件
- **直接传输原始二进制**，不做 base64 编码，请求体积比旧版小约 40%
- 上传采用「临时文件 + 原子替换」，不会因中断而覆盖已有小说
- 单文件上限 32MB，超出会在界面上提示
- 上传完成后自动保存到 `/userdisk/Music/小说/` 目录
- 使用完毕可一键停止服务，释放资源

后端自动按 **node → python3 → busybox httpd** 的顺序选择可用方案，
启动失败时界面会给出具体原因，并支持直接重试。

## 安装方式

将 `novel-reader` 文件夹复制到 PenMods 的插件目录下：/userdisk/PenMods/plugins/novel-reader/

安装完成后，在插件管理中即可打开。

也可以直接下载 Release 中的 `reader-v1.3.0.zip`，解压后把文件放进上述目录。

## 小说默认目录

小说默认读取目录为：/userdisk/Music/小说/

请把 `.txt` 小说文件放到这个目录下。阅读器打开后会自动扫描该目录中的 `.txt` 文件，并在"我的书架"中显示。

### 手动输入书名

手动输入书名时，不需要输入完整路径。比如小说文件是 `/userdisk/Music/小说/三体.txt`，在阅读器里输入 `三体` 或 `三体.txt` 即可打开。

## 上传小说的方式

### 前置条件

- 词典笔已经连接 Wi-Fi
- 电脑或手机和词典笔在同一个 Wi-Fi 下
- 词典笔具备 node、python3，或带 `httpd` applet 的 busybox 三者之一
  （PenMods 环境通常至少自备 busybox）

### 上传步骤

1. 打开阅读器，在首页点击 **「启动上传」** 按钮
2. 等待按钮变为红色 **「取消上传」**，上方显示绿色地址
   （启动期间显示「启动中…」；若失败会给出原因并可直接重试）
3. 在手机/电脑浏览器中打开显示的地址（例如 `http://192.168.1.23:8088`）
4. 在网页中点击或拖拽选择 `.txt` 文件，点击上传
5. 上传完成后，回到阅读器「我的书架」即可看到
6. 使用完毕可点击 **「取消上传」** 释放资源

## 常见问题

### 书架没有显示小说

- 检查小说是否放在 `/userdisk/Music/小说/` 目录下
- 确认文件后缀是 `.txt`（大小写均可）
- 尝试返回首页再重新进入书架

### 上传网页打不开

- 确认已点击「启动上传服务」按钮，首页显示绿色地址
- 确认手机/电脑和词典笔在同一个 Wi-Fi 下
- 确认地址输入正确（包括 `http://` 前缀和 `:8088` 端口）
- 服务需要 **node、python3，或带 `httpd` applet 的 busybox** 三者之一。
  注意：不少嵌入式 busybox 并未编译 `httpd` applet，此时界面会提示
  「busybox 缺少 httpd 组件」，请改用下面的 SSH/SFTP 方式上传

### 上传失败 / 上传后书架没有

v1.3.0 已修复此前的上传缺陷。若仍失败，请确认版本为 1.3.0 或更高：

- 返回首页再重新进入「我的书架」—— 书架会在进入时重新扫描目录
- 查看界面提示：新版本会回显服务端返回的具体错误，便于定位
- 若提示「上传超时」，说明文件可能过大（默认上限 32MB）

### 如何用 SSH/SFTP 上传（不依赖上传服务）

上传服务的所有后端都不可用时，可直接通过 SFTP 传文件：

1. 用 WinSCP（电脑）或 Termius（手机）通过 SFTP 连接词典笔
2. 连接信息：`IP:词典笔IP`、`端口:22`、`用户名:root`、
   `密码:PenMods 中设置的 SSH 密码`
3. 把 `.txt` 文件传到 `/userdisk/Music/小说/`

### 手动输入书名打不开

手动输入只需要输入小说名，不需要输入完整路径。例如文件路径是 `/userdisk/Music/小说/三体.txt`，输入 `三体` 或 `三体.txt` 都可以。

### 阅读进度丢失

- 阅读进度保存在本地 JSON 文件中（`/userdisk/.novel-reader-state.json`，双备份）
- 如果卸载插件或清除应用数据，进度会丢失
- 删除小说文件时，对应的进度与书签记录会一并清除（v1.3.0 起）
- **换章后回到旧章节进度归零、改名后从头开始读** —— 这两个问题在
  v1.3.0 已修复

## 更新日志 (v1.3.0)

### v1.3.0 — 上传链路与进度持久化修复

本版针对上传功能的**致命解码缺陷**与阅读进度的**丢失问题**做了系统性修复，
详细分析与验证记录见 [CODE_REVIEW.md](CODE_REVIEW.md)。

**上传功能（此前基本不可用）**
- 修复 `upload.cgi` 中 `data` 字段从未 URL 解码的问题。原实现下
  base64 的填充符 `=` 会以 `%3D` 形式传入并被 BusyBox `base64` 判为非法，
  **只有源文件字节数恰为 3 的倍数时才能上传成功**
- 修复 `$?` 检查对象错误（检查的是 `mkdir` 而非 `base64`）导致
  文件已写入成功却返回「上传失败」的误导性提示
- 修复对 base64 数据执行 `+` → 空格替换造成的数据损坏
- 上传改为**直接 POST 原始二进制**，移除 base64 与 URL 编码两层膨胀
  （请求体减小约 40%），并新增超时处理与服务端错误回显
- 新增 1MB 请求上限、分块读取与路径穿越防护
- 采用临时文件 + 原子替换，避免半截文件覆盖已有小说
- 启动失败后按钮可正常重试（原先需先点一次「取消」）
- busybox 后端改为实际探测 httpd applet，错误提示不再误导

**阅读进度**
- 进度改为按章节分别保存，修复「换章后回到旧章节进度归零」
- 重命名书籍时自动迁移进度与书签，修复「改名后从头开始读」
- 删除文件时一并清理进度与书签记录
- 修复状态文件写入的顺序竞争（曾导致「添加书签失败」）

**其他**
- 上传日志读取由同步 XHR 改为异步，消除每 500ms 的 UI 阻塞
- 修复 `get_ip` 在管道子 shell 中无法正确选定首个网卡地址的问题

### v1.2.1
