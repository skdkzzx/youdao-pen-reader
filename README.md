# 电子书阅读器 v1.2.0

一款专为词典笔设计的小说阅读器插件，支持本地 `.txt` 阅读与网页上传。

基于 [PenMods](https://github.com/PenUniverse/PenMods) 插件环境开发。

## 功能

- 自动扫描 `/userdisk/Music/小说/` 目录下的 `.txt` 文件
- 书架显示阅读进度，自动保存/恢复
- 逐章加载，极速打开大文件
- 分页/滚动双模式，7 种主题，3 档字号
- 书签、章节跳转、自动翻页
- 一键启动网页上传服务，浏览器直接传书

## 安装

将 `novel-reader` 文件夹复制到：

```
/userdisk/PenMods/plugins/novel-reader/
```

## 使用

### 阅读操作

| 操作 | 效果 |
|------|------|
| 点击左 1/3 | 上一页 |
| 点击右 1/3 | 下一页 |
| 点击中间 1/3 | 打开菜单 |
| 长按 | 返回首页 |

### 上传小说

1. 首页点击「▶ 启动上传服务」
2. 浏览器打开显示的 IP 地址（如 `http://192.168.1.x:8088`）
3. 选择 `.txt` 文件上传
4. 回到书架即可看到

### 小说目录

```
/userdisk/Music/小说/
```
