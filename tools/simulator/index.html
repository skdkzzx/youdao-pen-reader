布局度量（320×170 实测）

这是一个 HTML 还原的界面模拟器，不是真的在跑 QML —— iSH 里装不了 Qt 图形栈。布局参数（页面结构、尺寸、文案）取自 main.qml，在 320×170 的真实视口下渲染，用于检查 「在这个屏幕上放不放得下、看不看得清」。

交互是简化的：翻页、切页、切面板可用；文本换行按字号与行高估算， 与 Qt 的实际断行算法会有细微差异。键盘 ←/→ 翻页，Esc 关面板。

这个模拟器已经发现并修掉两个真问题：

① 阅读器正文被压住 —— getLinesPerPage 只减了上下边距， 没扣除底部状态栏，最后一行与状态栏重叠。
已修：新增 statusBarHeight 参数，正文与滚动模式的 bottomMargin 同步扣除，并补上定高 14px 的状态栏。

② 书架列表被工具栏挤没 —— 搜索框 + 筛选 + 排序共占 116px， 170px 屏上只剩 22px 给列表（约 0 本书）。
已修：搜索并入顶栏、排序改单键循环，固定占用降到 98px，列表可用 60px。
