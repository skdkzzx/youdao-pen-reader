# 界面模拟器

在浏览器中按 **320×170**（词典笔实际分辨率）还原界面，用于检查
「在这个屏幕上放不放得下、看不看得清」。

## 用法

打开 `index.html` 即可（无需构建、无依赖）。

## 它是什么 / 不是什么

**是**：QML 布局的 HTML 还原。页面结构、尺寸、文案都取自 `main.qml`
的显式数值，在真实视口尺寸下渲染，并实时给出布局度量
（每页行数、正文底部是否越界、书架列表可用高度等）。

**不是**：真正的 QML 运行时。本机（iSH）装不了 Qt 图形栈，
无法运行 QML。因此：

- 交互是简化的：切页、切面板、翻页可用
- 文字换行按字号与行高估算，与 Qt 的断行算法有细微差异
- 不模拟动画、手势、键盘输入

## 为什么要用它

「算得下但摆不下」这类问题靠读代码很难发现。本模拟器已发现并促成修复：

1. **阅读器正文被压住** —— `getLinesPerPage` 未扣除底部区域，
   最后一行与状态栏重叠
2. **书架列表被挤没** —— 搜索框 + 筛选 + 排序共占 116px，
   170px 屏上只剩 22px 给列表

改完 QML 后应同步更新本模拟器的参数，保持两者一致。
